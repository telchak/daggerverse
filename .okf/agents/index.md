# Agents

The AI agents and the shared agent library.

* [_agent_base (shared agent library)](agent-base.md) - The shared Python package that holds workspace tools, LLM builders, GitHub integration and router logic for Angie, Monty, Daggie and Speck.
* [Angie (Angular agent)](angie.md) - AI Angular development agent: assist, review, write tests, build and upgrade Angular projects, with the Angular CLI MCP server.
* [Daggie (Dagger CI specialist agent)](daggie.md) - AI agent that creates, explains, debugs and reviews Dagger modules and pipelines across SDKs, backed by dagger-mcp and runtime-cloned reference modules.
* [Goose (GCP operations agent)](goose.md) - AI GCP operations agent: deploy, troubleshoot, review, upgrade and assist across Cloud Run, Firebase Hosting, Vertex AI and Artifact Registry, with the gcloud MCP server.
* [Monty (Python agent)](monty.md) - AI Python development agent: assist, review, write tests, build/lint/typecheck and upgrade dependencies, with python-lft and pypi-query MCP servers.
* [Speck (spec-driven development agent)](speck.md) - AI agent that turns a prompt or GitHub issue into a spec, a technical plan, and a JSON task decomposition assigning agents and models, designed for GitHub Actions matrices.
